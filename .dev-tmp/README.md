# 本地开发临时目录（`.dev-tmp/`）

本目录用于集中存放本地开发过程中产生的临时文件，避免根目录和 `docs/` 无序膨胀。

## 使用约定

- 除本 `README.md` 外，`.dev-tmp/` 下所有文件均被 `.gitignore` 忽略，**不会提交到 Git**。
- 推荐子目录用途：
  - `logs/` — 构建日志、调试日志
  - `scratch/` — 一次性脚本、临时 JSON/补丁、实验数据
  - `notes/` — 个人开发草稿、未定稿方案（确认需长期沉淀的再整理进 `docs/`）
- **禁止**在仓库根目录新建 `.tmp*`、`.build*.log`、临时 `.md` 等零散文件。
